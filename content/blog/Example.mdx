# Demonstrating MDX Capabilities

Welcome to an example blog post. This file demonstrates how different markdown elements are styled using the custom MDX components designed for the Lokesh.OS terminal aesthetic.

## Typography and Text

This is a standard paragraph. It uses the `Geist` font for body text, ensuring readability while maintaining a clean, modern look.

You can use standard markdown formatting like **bold text** and _italic text_.

### Lists

Unordered lists look like this:

- First item in the list
- Second item with some more text to show wrapping
- Third item
  - Nested items are also supported (though they will use the same bullet style)

Ordered lists look like this:

1. First step
2. Second step
3. Final step

## Blockquotes

Blockquotes are styled to stand out with an aqua border and a slightly different background level.

> "Simplicity is the ultimate sophistication." - Leonardo da Vinci

## Code Snippets

Inline code like `const x = 10;` is styled with a distinct background and monospace font to separate it from the regular text.

For larger blocks of code, you can use fenced code blocks:

```javascript
function greet(name) {
  console.log(`SYS.INIT: Hello, ${name}!`);
}

greet("User");
```
