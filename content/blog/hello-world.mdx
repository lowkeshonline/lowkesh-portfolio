This site is the third version of my portfolio, and the first one that feels like it belongs to me. The earlier versions were trying to be a lot of things at once: a résumé, a project archive, a place to experiment with whatever framework I was learning that month. This one is quieter.

I started with a simple constraint: keep the writing and the work in front of the visitor, and let everything else stay out of the way. That meant fewer cards, fewer colors, and a lot more attention to spacing, type, and the small details that make a page feel considered.

## What changed

- The homepage now reads like an index instead of a brochure.
- Projects show the problem and the stack before the links.
- The activity graph and writing list use real data, not placeholders.
- Keyboard shortcuts, a command palette, and a visible focus state ship with it.

None of this is novel on its own. The interesting part is how it adds up: a page that feels like a working engineer's desk rather than a template.

## What I'm after

I want the interface to disappear. No decoration that has to explain itself, no motion that gets in the way, no copy that sounds like it was written for a landing page. Just the work, the context around it, and a clear next step.

That's the bar for this site, and for the things I build next.
